# 🚀 Proyecto Startups

Este proyecto tiene como objetivo analizar un conjunto de datos sobre startups para explorar factores asociados a su **valuación**, **rentabilidad** y **estatus posterior a la inversión**. Utilizando herramientas de ciencia de datos y machine learning, se entrenaron diversos modelos de clasificación y regresión para evaluar su capacidad predictiva sobre variables clave del mundo emprendedor.
